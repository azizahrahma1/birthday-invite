# Undangan Ulang Tahun Digital 💌

Project web undangan ulang tahun interaktif yang dibuat untuk tugas sekolah.

## ✨ Fitur Utama:
- Animasi amplop interaktif dengan efek hujan confetti/pita
- Pemutar musik latar belakang otomatis saat undangan dibuka
- Hitung mundur menuju hari acara (*Countdown timer*)
- Galeri kenangan foto
- Formulir RSVP dan Buku Ucapan (*Wishes*)

## 🛠️ Teknologi yang Digunakan:
- HTML5
- CSS3
- JavaScript
